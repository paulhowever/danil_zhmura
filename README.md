# Курсовая

Рабочая папка курсовой. Источник правды — эта папка (git), GitHub — приватная копия и история.

## Куда что класть

| Папка | Что там |
|---|---|
| `00_inbox/` | Всё подряд, не разбирая: файлы, скрины, ссылки, заметки. Разбирает Claude. |
| `requirements/` | Методичка, образец плана и титульника, приказы, требования кафедры, утверждённый план, письма научрука. |
| `sources/` | Литература: PDF, статьи, книги. В `sources/notes/` — конспект по каждому источнику. |
| `data/` | Данные, расчёты, таблицы, код, если работа их требует. |
| `text/` | Текст работы по главам в Markdown: `00_введение.md`, `01_глава.md`, … |
| `assets/` | Рисунки, схемы, графики, которые идут в текст. |
| `build/` | Собранный `.docx` / `.pdf`. В git не попадает, пересобирается. |
| `notes/` | Рабочие заметки: решения, вопросы научруку, что осталось. |

## Как идёт работа

1. Материалы падают в `00_inbox/`.
2. Claude раскладывает их по папкам и пишет конспекты источников.
3. Текст пишется в `text/` по утверждённому плану.
4. `text/*.md` собирается в `.docx` по шаблону кафедры (pandoc + `requirements/template.docx`).
5. Финальная вычитка и мелкая вёрстка — в Word, перед сдачей.
